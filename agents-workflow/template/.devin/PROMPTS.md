# PROMPTS.md — готовые промпты для запуска ИИ-сессий

Скопируй нужный блок целиком и кинь ИИ в новую сессию. Один промпт =
одна сессия = один режим.

---

## 1. Главный — автономная работа (default)

```text
Прочти .devin/WORKFLOW.md — это твой оркестратор, вся система внутри
него. Потом AGENTS.md — закон проекта. Работай по циклу: бери верхний
item по приоритету, делай минимальным диффом, прогоняй гейты, коммить,
отчитывайся шаблоном после каждого раунда. Не выдумывай работу —
пустая очередь = STOP. Сомневаешься — пиши вопрос в .devin/QUESTIONS.md
и бери другой item. Начинай.
```

## 2. Mentor — работа + обучение

```text
Прочти .devin/WORKFLOW.md и AGENTS.md. Работай в режиме mentor: та же
очередь, но перед каждой нетривиальной правкой пиши Q-entry в
.devin/QUESTIONS.md и жди моего ответа. После каждой правки давай
Lesson — 3-6 строк какой паттерн/антипаттерн трогали и почему это
масштабируется. Цель — я учусь систем-дизайну на своём коде, а ты
чистишь проект.
```

## 3. Холодный старт — ИИ не знает проект

```text
Перед любой работой прочти: .devin/WORKFLOW.md (как работать),
AGENTS.md (что правда в архитектуре и дефектах), .devin/QUESTIONS.md
(куда писать вопросы), .devin/BOARD.md (открытые находки).
Никаких правок пока не прочтёшь все четыре. После — работай по циклу
из WORKFLOW.md.
```

## 4. Узкие задачи

```text
# Только аудит без правок:
Прочти .devin/workflows/ai_slop_audit.md + AGENTS.md. Найди
антипаттерны, запиши S###-строки на доску .devin/BOARD.md.
Код не трогай.
```

```text
# Только проверка сделанного (отдельная сессия, не чистильщик):
Прочти .devin/workflows/cleanup_verify.md. Проверь Done-строки в
.devin/done-log.md — недоверчиво, перепроверяй grep'ом, вердикты в лог.
```

```text
# Конкретный дефект (пример):
Прочти AGENTS.md §Confirmed defects. Фикси defect #N — <название>.
Тесты-ловушки уже есть. Минимальный дифф, гейты, отчёт шаблоном.
```

---

## Правила для человека (держись сам)

- Один промпт = одна сессия = один режим. Не смешивай «почини + научи +
  аудируй» — ИИ расползается.
- Ответил в QUESTIONS.md → скажи «продолжай» — иначе оно ждёт.
- Красный отчёт Gates → не проси следующий item — сначала чинка красного.
- Хочешь скорость → «прогони WORKFLOW». Хочешь учиться → «прогони mentor».
  Не оба сразу.
